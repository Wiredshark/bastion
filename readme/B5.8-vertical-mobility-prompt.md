> **For Ben:** paste into a game-build session (or queue before B6). The vertical-reachability trap has
> bitten FOUR times (B5 ×3, B5.5 ×1) — every block hand-patches test geometry around it, and B6 hauling
> paths colonists over terrain constantly. Fix the mechanism now. Standard protocol: branch → build →
> self-test → merge → tag `bastion-block-B5.8`.

## THE THREE MECHANISMS (in order of preference — cheapest first)

### 1. SCRAMBLE (use what exists)
Veloren humanoids HAVE a climbing capability (player climbing is a shipped mechanic). Investigate first:
- Wire colonist pathing/locomotion to **step up/down 1-block ledges natively** (if not already — verify
  what ARRIVE_DIST masking hid) and **scramble short vertical faces (2–3 blocks)** using the existing
  climb machinery (energy/stamina rules can be relaxed or bypassed for the Colonist body — they're
  workers, not players).
- Pathfinding must KNOW about it: the path cost model treats 1-step as walkable, 2–3-block scrambles as
  traversable-at-cost (slower). This alone likely kills most of the trap's manifestations.

### 2. STAIR-CARVING (terrain the colony owns)
When a job's path needs a vertical transition beyond scramble range **through diggable terrain inside
colony designations/claims** (mine pits, quarry faces):
- The job system auto-inserts a **carve-steps sub-job**: dig a 1-wide staircase along the slope (the B5
  dig verb, pathed as a ramp — the exact staircase the harness hand-carved in B5's fix, now generated by
  the system). Spoil follows normal drop→pile rules.
- Scope guard: auto-carve ONLY inside the colony's own designated areas (never carve the wilderness to
  chase a deer); elsewhere the path is simply reported unreachable as today. This is the interim slice of
  the §3v access-is-part-of-the-dig-plan rule — the mine framework later supersedes it with planned
  access, and this mechanism remains the fallback.

### 3. LADDERS (buildable vertical links)
- A **ladder** as a buildable/placeable (check for an existing ladder sprite/block first — Veloren
  structures include climbable elements; reuse if present, else a simple 1-block-face sprite chain).
  Colonists path onto and climb it (climbable-block flag → pathfinding treats the ladder column as a
  traversable vertical edge).
- Placement: player-directed now (a designation/tool: drag a vertical line on a face); autonomous
  placement (colony ladders its own mines/buildings) comes with B-AG6/mine framework.
- Asset note: ladder variants (wood/rope) → wishlist; the asset session can generate them; ONE working
  ladder block/sprite suffices for this patch.
