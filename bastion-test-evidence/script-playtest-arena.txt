note THREE-MODE PLAYTEST -- modes 1+2, FLAT ARENA deep dive.
note ONE leg feeds BOTH readers: the inspects are mode 1 (LLM text play), the
note `ascii` frames are mode 2 (DF-style map play). They must agree; where a
note counter says "alive" and the frame says "frozen", THE FRAME WINS and the
note counter's producer is the thing under suspicion.
note
note WHY THIS SCRIPT EXISTS: every arena fixture to date scored a COUNTER, and
note a counter cannot answer "does this colony look alive?". Eight frames on a
note fixed cadence can -- a working colony and a stuck one render differently
note even when their totals agree. These notes are the playtest's HYPOTHESES;
note they are written before the run and are scored against it afterwards.
note
note DECLARED RUN LENGTH (declare-run-length-before-launch):
note   600 settle + 8 x 1500 cycle + 300 intervention ack = 12,900 ticks
note   = 430 game-seconds = ~7 game-minutes. Wall time is deliberately NOT
note   declared: headless compression is a harness property, not this
note   script's. Extending the run because a frame looks interesting is NOT
note   allowed -- the length is fixed here and scored at this length.
note
note ARENA GEOMETRY (script-arena-chop.txt's measured datum, unchanged):

note VOID CONDITIONS, named BEFORE the run so a void cannot be read as a fail:
note   V1 a frame that is mostly `?` is UNLOADED TERRAIN, not an empty arena.
note      If cycle 1 renders mostly `?`, the presence radius is the defect,
note      every later frame is uninterpretable, and NOTHING is scored.
note   V2 `count_items` flat at zero for the whole leg with SEED_FOOD set
note      means the seed never landed. The build->cook->eat axis is then
note      VOID, not FAIL -- there was no input for the pipeline to conserve.
note   V3 if `ascii` renders colonists but NOT their job state, "is anyone
note      standing still" is answerable ONLY by comparing consecutive frames.
note      A single frame cannot distinguish idle from mid-path; say so rather
note      than scoring stillness off one picture.
